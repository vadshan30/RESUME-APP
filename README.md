## 📌 Overview

**AI-Powered Resume Assistant** is a web-based career assistant that uses **AI and Natural Language Processing (NLP)** to analyze resumes and provide personalized career insights.

It helps users understand how well their resume matches a job, identify missing skills, improve their applications, and prepare for interviews.

### 🎯 Core Capabilities

* 📄 Resume Analysis
* 🎯 Job Description Matching
* 📈 Skill Gap Analysis
* ✍️ AI Cover Letter Generation
* 🎤 Interview Preparation
* 📊 Resume & Career Analytics

---

## ✨ Features

### 📄 Resume Analysis

* Upload resumes in PDF format
* Extract resume content
* Analyze skills and qualifications
* Identify strengths and weaknesses
* Provide ATS-oriented insights

### 🎯 Job Matching

* Compare resume with job descriptions
* Generate match percentage
* Identify missing skills
* Highlight matching qualifications
* Suggest improvements

### 📈 Skill Gap Analysis

* Detect missing technical skills
* Identify relevant soft skills
* Highlight areas for improvement
* Provide personalized learning suggestions

### ✍️ AI Cover Letter Generator

* Generate personalized cover letters
* Tailor content to specific job descriptions
* Use information extracted from the resume
* Produce professional application content

### 🎤 Interview Preparation

* Generate technical questions
* Generate HR questions
* Provide personalized preparation guidance
* Focus preparation on relevant skills

### 📊 Career Analytics

* Resume scoring
* Skill analysis
* Job match insights
* Career improvement recommendations

## 🚀 Getting Started

### Prerequisites

* 🐍 Python 3.12
* 🌐 Modern web browser
* 📦 pip
* 🔧 Git

---

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/vadshan30/RESUME-APP.git
cd RESUME-APP
```

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

If backend-specific dependencies are required:

```bash
cd backend
pip install -r requirements.txt
```

---

### 3️⃣ Run the Application

From the project root:

```bash
python run.py
```

Alternatively, run the backend directly:

```bash
cd backend
python app.py
```

---

### 4️⃣ Open the Application

After starting the server, open the local application URL displayed in your terminal.
