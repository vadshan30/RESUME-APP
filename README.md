# 🚀 AI-Powered Resume Assistant

An intelligent career assistant that analyzes resumes, matches job requirements, identifies skill gaps, generates cover letters, and provides interview preparation guidance using AI.

## 📌 Features

### 📄 Resume Analysis

* Upload resumes in PDF format
* Extract and analyze resume content
* Identify strengths and weaknesses
* Generate ATS compatibility insights

### 🎯 Job Matching

* Compare resume with job descriptions
* Calculate match percentage
* Highlight missing skills and qualifications
* Suggest improvements

### 📈 Skill Gap Analysis

* Detect missing technical and soft skills
* Recommend learning resources
* Generate personalized upskilling roadmap

### ✍️ AI Cover Letter Generator

* Create tailored cover letters
* Customize content based on job descriptions
* Professional formatting and structure

### 🎤 Interview Preparation

* Generate interview questions
* Technical and HR question recommendations
* Personalized preparation guidance

### 📊 Analytics Dashboard

* Resume scoring
* Skill distribution analysis
* Job match visualization
* Career insights

## 🚀 Getting Started

### Prerequisites

* Java 17+
* Maven
* Node.js
* Python 3.10+
* MySQL

### Installation

1. Clone the repository

```bash
git clone https://github.com/vadshan30/RESUME-APP.git
```

2. Navigate to the project

```bash
cd RESUME-APP
```

3. Start Backend

```bash
mvn spring-boot:run
```

4. Start Frontend

```bash
npm install
npm start
```

5. Start AI Services

```bash
python app.py
```
